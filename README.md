# GameEngine

A place for challenging myself to create my own Game Engine, for my future Adventures as Engine Software Engineer

#### Setting Up the Project

Download LLVM from

- LLVM: https://github.com/llvm/llvm-project/releases/tag/llvmorg-22.1.0

- Install LLVM and add it to the system path

Download Vulkan SDK and install it

- Vulkan SDK: https://vulkan.lunarg.com/
- Check if it is added to the system path
    - CMD: echo %VULKAN_SDK%
    - Powershell: $env:VULKAN_SDK

- Setup Project in VSCODE and setup build system for it
